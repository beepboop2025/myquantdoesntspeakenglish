# Local font files

The site serves Fraunces and DM Mono from its own origin so a page view does not
contact Google Fonts. The TTF files are copied from the matching
`@expo-google-fonts` packages used by the mobile app. Both families are licensed
under the SIL Open Font License 1.1; the unmodified licence texts are included
as `OFL-Fraunces.txt` and `OFL-DMMono.txt` in this directory.

Do not remove or rename the licence texts when redistributing the font files.
